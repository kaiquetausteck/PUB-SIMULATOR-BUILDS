# Venture Simulator — builds de testes

## Baixar e jogar

1. [Baixe VentureSimulatorLauncher.exe](https://github.com/kaiquetausteck/PUB-SIMULATOR-BUILDS/releases/latest/download/VentureSimulatorLauncher.exe).
2. Coloque o arquivo na Área de Trabalho e abra.
3. No primeiro uso, informe a chave recebida, escolha a pasta do jogo e clique em **Baixar e instalar**.
4. Ao terminar, clique em **Jogar**.

Existe apenas esse launcher portátil, sem instalador separado. Nas próximas aberturas, ele reconhece a instalação e verifica e baixa atualizações automaticamente. Feche o jogo antes de atualizar. Sem internet, a versão instalada continua disponível. Cancelar ou falhar uma atualização preserva a versão anterior e os saves ficam separados.

Windows 10/11 x64 com .NET Framework 4.8. Internet necessária para o primeiro download. A chave e a localização do jogo ficam no perfil do Windows: mover o launcher não perde a instalação. Para atualizar o próprio launcher, substitua o executável pelo download mais recente.

Os pacotes `game.*.bin` são criptografados e baixados pelo launcher. Não precisam ser baixados manualmente. A chave é enviada separadamente e não deve ser publicada. O código-fonte permanece privado; este repositório contém somente a distribuição.

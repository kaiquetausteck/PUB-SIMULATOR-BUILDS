# Venture Simulator — builds de testes

Este repositório distribui o launcher e os pacotes **criptografados** do jogo.
O código-fonte permanece em um repositório privado.

## Instalar e jogar

1. [Baixe o instalador do launcher](https://github.com/kaiquetausteck/PUB-SIMULATOR-BUILDS/releases/latest/download/VentureSimulatorSetup.exe).
2. Execute `VentureSimulatorSetup.exe` e informe a chave recebida com seu convite.
3. Abra **Venture Simulator** pelo atalho criado na Área de Trabalho.
4. Clique em **Baixar e instalar**. Ao terminar, clique em **Jogar**.

Requisitos do launcher: Windows 10/11 de 64 bits com .NET Framework 4.8 ou
superior. É necessário acesso à internet para a instalação inicial.

## Atualizações

O launcher consulta novas versões ao abrir. Quando houver uma atualização,
você pode clicar em **Atualizar** ou continuar com **Jogar** na versão instalada.
Feche o jogo antes de atualizar. Sem internet, a versão instalada continua
disponível. Os saves ficam separados dos arquivos de instalação.

Os arquivos `game.*.bin` nas releases são baixados automaticamente pelo launcher;
não é necessário baixá-los ou extraí-los manualmente. A chave não está neste
repositório e não deve ser publicada aqui. Ela é necessária para instalar a build.

[Ver todas as versões](https://github.com/kaiquetausteck/PUB-SIMULATOR-BUILDS/releases).
